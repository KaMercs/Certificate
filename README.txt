How to use:
1. Extract this ZIP file.
2. Open index.html in a web browser.
3. To publish online, upload the extracted folder to a static hosting service such as GitHub Pages, Netlify, or Vercel.

The page is responsive and includes certificate previews, a full-screen image viewer, and download links.
Privacy reminder: both certificate images contain personal information. Review them before publishing publicly.
